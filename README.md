# Tic-Tac-Toe-java
A GUI-based Tic-Tac-Toe game built with Java Swing featuring two-player gameplay, winner/tie detection, and replay functionality.

This project was developed to practice Java programming, GUI development, event handling, and Object-Oriented Programming concepts.

**Features**
1. Two-player gameplay
2. ❌ Player X and ⭕ Player O
3. Interactive graphical user interface
4. 3×3 Tic-Tac-Toe board
5. 🏆 Automatic winner detection
6. Automatic tie detection
7. Visual highlighting of winning combinations
8. Replay button to restart the game
9. Event-driven interaction using Java Swing

**How the Game Works**

The game starts with Player X.
Players take turns clicking an empty cell on the 3×3 board.
The current player's symbol is placed in the selected cell.
The program checks for:
Horizontal winning combinations
Vertical winning combinations
Diagonal winning combinations
When a player wins, the winning cells are highlighted.
If all 9 cells are filled without a winner, the game displays Tie!
The Replay button resets the board and starts a new game.
